# dom-manipulation-lego-starwars
pt-br:
Projeto web para praticar manipulação do DOM com HTML, CSS e JavaScript, usando personagens de Star Wars em Lego como contexto visual. O objetivo é entender como elementos da página são estruturados, estilizados e manipulados, criando uma base para compreender a lógica de automação de testes E2E.

en-us:
Web project to practice DOM manipulation with HTML, CSS, and JavaScript, using Lego Star Wars characters as a visual context. The goal is to understand how page elements are structured, styled, and manipulated, building a foundation for understanding the logic behind E2E test automation.
