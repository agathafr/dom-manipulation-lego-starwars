# DOM Manipulation - Lego Star Wars

> Projeto de estudo para praticar manipulação do DOM com HTML, CSS e JavaScript.

Este projeto usa personagens de **Star Wars em Lego** como contexto visual para entender como os elementos de uma página web são estruturados, estilizados e manipulados.

A proposta é construir uma base para compreender melhor a lógica por trás da automação de testes E2E, especialmente a forma como ferramentas como Cypress, Playwright e Selenium localizam e interagem com elementos na tela.


## Objetivo

Praticar os fundamentos de HTML, CSS e JavaScript, com foco em manipulação do DOM.

## Tecnologias

- HTML
- CSS
- JavaScript

## Conceitos estudados

- Estrutura HTML
- Seletores CSS
- Objetos em JavaScript
- Funções em JavaScript
- Manipulação do DOM
- Relação entre DOM e testes E2E

## English version

> Study project to practice DOM manipulation with HTML, CSS, and JavaScript.

This project uses **Lego Star Wars characters** as a visual context to understand how web page elements are structured, styled, and manipulated.

The goal is to build a foundation for understanding the logic behind E2E test automation, especially how tools like Cypress, Playwright, and Selenium locate and interact with elements on the screen.
